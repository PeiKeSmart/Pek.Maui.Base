# 🔧 推送消息未收到问题排查

## 📋 问题现状
- ✅ JPush推送已发送（控制台显示推送成功）
- ❌ APP没有收到通知（通知栏无显示）

## 🔍 逐步排查清单

### 1. 检查推送发送状态
在JPush控制台确认：
- [ ] 推送状态显示"推送成功"
- [ ] 目标设备数 > 0
- [ ] 没有错误信息

### 2. 检查Registration ID
确认使用的Registration ID：
- [ ] 是最新获取的ID（不是缓存的旧ID）
- [ ] ID格式正确（通常是一长串字母数字）
- [ ] 在控制台推送时使用了正确的ID

### 3. 检查应用权限设置

#### Android系统通知权限
```
设置 → 应用管理 → JPushTestDemo → 通知
确保：
✅ 允许通知：开启
✅ 显示通知：开启
✅ 锁屏通知：开启
```

#### 电池优化设置
```
设置 → 电池 → 电池优化 → JPushTestDemo
选择：不优化
```

#### 自启动权限
```
设置 → 应用管理 → JPushTestDemo → 权限 → 自启动
确保：开启
```

### 4. 检查推送消息格式

确认在JPush控制台发送的消息类型：
- [ ] 选择了"通知栏消息"（不是"自定义消息"）
- [ ] 设置了标题和内容
- [ ] 没有设置过于复杂的附加字段

### 5. 检查网络连接
- [ ] 设备有稳定的网络连接
- [ ] 可以正常访问外网
- [ ] 没有公司防火墙阻挡

## 🧪 调试步骤

### 步骤1：重新获取Registration ID
1. 打开APP
2. 点击"获取Registration ID"
3. 记录最新的ID
4. 用这个新ID在控制台测试推送

### 步骤2：检查JPush连接状态
在APP中查看调试日志：
```
JPush连接状态: True  (必须是True)
Registration ID: [一串字符]  (不能为空)
```

### 步骤3：测试不同推送方式

#### 方式1：推送给所有用户
在JPush控制台：
1. 选择"推送给所有用户"
2. 设置简单的标题和内容
3. 立即推送

#### 方式2：指定Registration ID
1. 选择"指定用户"
2. 输入Registration ID
3. 推送

### 步骤4：检查推送历史
在JPush控制台查看：
1. 推送记录
2. 送达统计
3. 错误日志

## 🔧 常见问题解决

### 问题1：通知权限被拒绝
**解决**：
```
设置 → 应用 → JPushTestDemo → 通知 → 开启所有通知权限
```

### 问题2：电池优化限制
**解决**：
```
设置 → 电池 → 电池优化 → JPushTestDemo → 不优化
```

### 问题3：后台应用限制
**解决**：
```
设置 → 应用 → JPushTestDemo → 电池 → 后台活动 → 允许
```

### 问题4：Registration ID过期
**解决**：
1. 重新启动APP
2. 重新获取Registration ID
3. 使用新ID测试推送
